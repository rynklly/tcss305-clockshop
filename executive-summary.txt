Assignment Overview:

 The goal of this assignment was to create a Clock class along with a ClockShop
 class which would manage an ArrayList of Clocks. Some key functionality is the
 ability to read from a text file to fill an ArrayList with Clocks, search, sort,
 and add clocks in the ArrayList, as well as output a file with the information
 from the clocks in the ArrayList.

Extra Credit:
I added a :|\R+ delimiter to the scanner and used nextInt() to store the values.
The \R accounts for both unix and windows newlines and the + allows the scanner to
bypass any blank lines without exiting the while loop early.

For setToCurrentTime() I used the java.time.LocalTime class to avoid the need
to do arithmetic on the system milliseconds and convert to local time. I was then
able to use setHour(), setMinute(), and setSecond() with the current local time
as parameters to set the clock correctly.

I then wrote tests for a clock generated using the default constructor and one
constructed using parameters. In order to account for small changes in time between
setting clocks to local time and comparing to local time for the test, I converted
the Clocks time to total seconds and compared that to LocalTime.toSecondOfDay() and
confirmed the difference was less than two seconds.
